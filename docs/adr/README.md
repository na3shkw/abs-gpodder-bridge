## 書き方

- ファイル名は `<3 桁の番号>-<短い英語名>.md`。番号は続きから振る。
- 見出しは「状況・選択肢・決定・結果」の 4 つ。冒頭に状態・日付・関連する仕様の節を書く。
- 採用した ADR は書き換えない。方針を変えるときは新しい ADR を書き、古い方の状態を「[新しい番号] で置き換え」に変える。
- 仕様書の関係する節の末尾に、ADR へのリンクを足す。

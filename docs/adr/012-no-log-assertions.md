# 012. ログはテストで確かめない

- 状態：採用
- 日付：2026-10-19
- 関連：[仕様](../spec.md) 2.1 節（元の論点 C1）

## 状況

仕様では、ログのレベル（例：照合できない記録は debug、ABS との通信の失敗は warn）と、出力先（標準出力）だけが決まっている。1 行の書式（JSON か、どんな項目を含むか）は決まっていない。

書式が決まっていないので、テストで「warn が出た」を確かめようとすると、テストが勝手に書式を決めることになる。

## 選択肢

- ログの書式を仕様で決め、テストで確かめる
- ログはテストで確かめない

## 決定

ログはテストで確かめない。書式は実装に任せる。

## 結果

- 仕様もテストも、ログの書式に縛られない。
- ログが正しく出ているかは、テストでは守られない。確かめたくなったら、そのときに書式を仕様に足す。
